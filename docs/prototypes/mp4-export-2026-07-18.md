# MP4 Export Prototype: 2026-07-18

The isolated media worker loaded a persisted `render-plan.json` from a real journaled project and produced:

| Property | Result |
| --- | --- |
| Codec | H.264 |
| Resolution | 1920 x 1080 |
| Frame rate | 30 fps |
| Duration | 15.667 s |
| File size | 184,386 bytes |
| Container option | fast-start MP4 |

The exporter currently supports:

- landscape, portrait, and square scale/pad framing;
- first screen source;
- optional camera bottom-right overlay;
- microphone/system-audio mix;
- loudness normalization;
- mid-track silence insertion through trim/generated-silence/concat filters;
- bounded whole-track playback-rate automation.

Enabled unsupported automation fails explicitly. The user can disable that event in the timeline and export without modifying source media.

## Silence validation

A real tone WAV was exported with a 200 ms `InsertSilence` event at 2 seconds. FFmpeg `silencedetect` measured:

- start: 2.000062 s;
- end: 2.199927 s;
- duration: 0.199865 s.

The final H.264/AAC MP4 remained exactly 5.000 seconds.

The WinUI timeline persists the current plan and launches `SevenRecord.Media.Worker export-plan`; FFmpeg never runs inside the UI process.
