# Product

## Register

product

## Platform

web

## Users

The primary users are software educators, developer advocates, product marketers, course creators, founders, and vloggers who record applications, websites, demos, tutorials, and narrated walkthroughs. They need to move from recording to a publishable video without manually rebuilding every zoom, cut, caption, and presenter layout.

The first production target is Windows desktop. The interface may use web technology, but recording, media processing, storage, and export must behave as a local desktop product. macOS portability is a later goal rather than an MVP constraint.

## Product Purpose

7Record records a screen, cursor activity, system audio, microphone, and camera as independently editable sources. It then creates a strong first edit automatically: purposeful cursor zooms, presenter layouts, silence and loading compression, captions, audio cleanup, and creator-ready framing.

Success means a user can record a polished software tutorial or screen-led vlog, review the automatic edit, make a few deliberate adjustments, and export a publishable video substantially faster than editing the same material in a general-purpose video editor.

## Positioning

The screen recorder that understands software demos and turns raw capture into a nearly finished creator video.

## Brand Personality

Focused, cinematic, and trustworthy. The product should feel like a quiet editing room built for concentration: precise controls, restrained visual energy, fast feedback, and no decorative complexity competing with the recorded content.

## Anti-references

Avoid an OBS-style wall of technical controls for the default workflow, a generic SaaS dashboard, a toy-like mobile editor enlarged for desktop, excessive glass effects, decorative gradients, nested cards, and automation that hides or destructively changes the source media.

## Design Principles

- Record sources and intent, not only flattened pixels.
- Produce a useful first edit while keeping every automation reversible.
- Keep the creator in flow with immediate preview and keyboard-first control.
- Make common tutorial decisions automatic and exceptional decisions easy to override.
- Preserve local privacy and project recoverability by default.

## Accessibility & Inclusion

Target WCAG 2.2 AA for the application interface. Support complete keyboard navigation, visible focus, high-contrast states, captions, reduced motion, non-color status cues, scalable UI text, and automation controls that remain understandable without relying on animation.
